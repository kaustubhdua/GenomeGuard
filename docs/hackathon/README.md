# Hackathon materials

GenomeGuard was built for Tech Eximius 2.0, Track 2 (Agentic AI for Healthcare). These files are
submission and presentation aids. They are not needed to run or understand the project.

| File | Purpose |
|---|---|
| [FINAL_JUDGE_RUNBOOK.md](FINAL_JUDGE_RUNBOOK.md) | Go/no-go checklist and a three-minute demo script |
| [HACKATHON_RELEASE_GATE.md](HACKATHON_RELEASE_GATE.md) | Evidence matrix mapping judging criteria to what was verified |
| [JUDGE_READINESS_PLAN.md](JUDGE_READINESS_PLAN.md) | Research-backed readiness plan |
| [ROADMAP.md](ROADMAP.md) | Day-by-day plan to the submission deadline |
| [slide-inputs.md](slide-inputs.md) | Text for slides and likely judge questions |

How the four Track 2 themes map to the product:

| Theme | Where it shows up |
|---|---|
| Decision support | Case summaries and a read-only steward copilot that recommends; rules cap it and a human decides |
| Information management | Consent, risk, privacy budget and a tamper-evident audit chain for every release |
| Patient interaction | Patient portal: see who used statistics that included you, ask fixed questions, withdraw consent |
| Workflow automation | Automatic triage into approve, protect, deny or hold; anomalous accounts are frozen |
